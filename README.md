# WhatsApp Number Checker

Проверяет список номеров на наличие WhatsApp через твой личный/рабочий аккаунт (whatsapp-web.js). Управление — через веб-страницу, открывается с телефона.

## ⚠️ Важно прочитать перед запуском

1. **Это неофициальный метод.** whatsapp-web.js эмулирует WhatsApp Web через привязку твоего аккаунта по QR. Это нарушает условия использования WhatsApp — официального способа массово проверять номера не существует.
2. **Риск бана номера.** При проверке сотен/тысяч номеров подряд WhatsApp может временно или навсегда заблокировать привязанный аккаунт. В коде уже стоят случайные задержки (4-9 сек между проверками + пауза раз в 40 проверок), но это снижает риск, а не убирает его.
3. **Рекомендации:**
   - Используй запасной номер / бизнес-сим, а не основной личный аккаунт.
   - Для 1000+ номеров — раздели на несколько дней (по 200-300 в день), а не всё разом.
   - Не выключай сервер во время проверки — прогресс хранится в памяти, при перезапуске текущая проверка потеряется (результаты можно скачать в любой момент по кнопке "Скачать CSV").
4. Сессия авторизации сохраняется в папке `.wwebjs_auth` — не удаляй её, иначе придётся сканировать QR заново.

## Локальный запуск (для теста на компьютере)

```bash
npm install
npm start
```

Откроется на `http://localhost:3000`. Дальше — с телефона (если телефон в той же сети) можно зайти по `http://<IP-компьютера>:3000`.

## Деплой на хостинг (чтобы управлять полностью с телефона)

Нужен хостинг с поддержкой Node.js + возможностью ставить Chromium (для puppeteer) и **постоянным диском** (чтобы не слетала авторизация при перезапуске).

### Вариант 1: Railway.app (проще всего)
1. Зарегистрируйся на railway.app, привяжи GitHub.
2. Залей этот проект в GitHub-репозиторий (или используй "Deploy from local folder" через Railway CLI).
3. New Project → Deploy from repo.
4. В настройках добавь Volume, примонтируй в `/app/.wwebjs_auth` — чтобы сессия не терялась.
5. После деплоя Railway даст публичную ссылку (`https://xxx.up.railway.app`) — открывай её с телефона, сканируй QR, работай.

### Вариант 2: VPS (DigitalOcean, Timeweb, Reg.ru и т.п., $4-6/мес)
1. Арендуй сервер (Ubuntu 22.04), зайди по SSH (с телефона можно через приложение Termius).
2. Установи Node.js 20+ и зависимости для Chromium:
   ```bash
   sudo apt update && sudo apt install -y chromium-browser
   ```
3. Залей проект (git clone или scp), `npm install`, затем `npm start` (лучше через `pm2` чтобы не падало):
   ```bash
   npm install -g pm2
   pm2 start server.js --name whatsapp-checker
   pm2 save
   ```
4. Открой порт 3000 (или настрой nginx + домен), заходи с телефона по `http://IP-сервера:3000`.

## Как пользоваться

1. Открой сайт с телефона.
2. Отсканируй QR своим WhatsApp (Настройки → Связанные устройства → Привязать устройство).
3. После подключения — вставь номера (по одному в строке, с кодом страны, без "+", например `994501234567`).
4. Нажми "Начать проверку" — прогресс и результаты видно сразу, можно свернуть и вернуться позже.
5. По завершении — кнопка "Скачать CSV".

## Формат номеров

Код страны + номер, без пробелов, `+`, скобок и тире:
```
994501234567
79161234567
```
